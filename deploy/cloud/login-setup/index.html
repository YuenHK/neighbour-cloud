設定鄰伴嘅 Google 登入

只需設定一次，之後用指定 Google 帳戶登入。唔使提供密碼、API key 或 Client secret。

先喺 Google 建立網頁登入 Client ID
  1. 開啟 Google Auth Platform → Clients，選現有或新嘅免費專案。
  2. 如要求先設定 Branding，應用程式名稱填「鄰伴」，使用自己嘅支援電郵；只保留基本 email／profile／openid，唔使開計費。
  3. Create client → Web application，名稱填「鄰伴雲端登入」。
  4. 喺 Authorized JavaScript origins 加入以下三行：正在讀取…http://localhosthttp://localhost:8924
  5. 建立後只複製 Client ID（結尾係 apps.googleusercontent.com）到下方。唔需要 Client secret，亦唔使下載憑證。

正在準備本機設定…

成功後只會把已核對嘅帳戶設定加密存喺本機；唔會公開平台、上傳居民資料或操作機械人。
