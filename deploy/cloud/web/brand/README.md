# Neighbour house mascot

Original platform mascot generated with the built-in imagegen tool on 2026-11-03, based on the platform's existing little-house illustration and a soft plush-toy direction. The user chose an apricot-orange roof, not green. No commercial toy name or logo is included.

The transparent master is retained at `design/mascot-20261103/neighbour-house-apricot-master.png`. These files are technical size/format exports from that master, with alpha retained: 48 KB WebP for the loading animation, PNG browser/app/home-screen icons. Animation uses CSS only; no video, audio, external service or resident data is involved. Full generation prompt is saved with the master in `design/mascot-20261103/PROMPT.md`.
