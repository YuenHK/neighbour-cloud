# 數字人動作及預設視線追蹤

居民畫面及模型準備好後，預設嘗試啟動裝置內的視線與手勢追蹤。瀏覽器首次權限由使用者批准；主動關閉或拒絕後不反覆重試。切換分頁會釋放鏡頭，返回時只恢復原先已啟動的追蹤。影像不傳到雲端，不辨認身份。

動作直接參考本輪已有的廣東話內容，分為問候、解說、肯定、多謝、喜悅和柔和關懷。壓力或危險內容優先使用關懷動作。語音段落間保留動作節奏，問候揮手不會在整段朗讀不停重複；不額外呼叫模型或語音平台。

沒有正在輸入、等候或朗讀時，安靜待機會間歇環顧並揮手迎接。進行中的對話須安靜至少75秒，關懷對話不主動打招呼；不會自行出聲。追蹤到用家時以用家位置為先。減少動態效果設定仍受尊重。

VRM使用模型原有的頭、肩、手臂和手腕骨架。Live2D只使用該模型實際具備的身體及手臂參數，欠缺手臂骨架時保留柔和頭部和身體動作；不偽造參數或改動作者模型。所有疊加動作有界，結束後恢復原有姿勢，保留嘴形、眨眼、已選模型與已儲存設定。

Gemma、Microsoft曉曼F0及原有免費服務保持。這次不建立工單、不清資料、不改用量或金鑰，也不連接或操作EP/S1。真人鏡頭位置、不同模型的揮手幅度仍由使用者在實際裝置驗收。
