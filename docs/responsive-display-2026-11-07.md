# 居民數字人自動調節畫面

居民畫面按瀏覽器可用闊度、高度和方向即時調整，不依賴裝置名稱，也不改管理工作台布局。轉動手機、調整視窗或更換螢幕時，不會重開對話或發佈另一份模型設定。

- 橫向電腦及電視保留原有左右布局、頂部導覽及模型偏好。
- 直向手機、平板、電視及LED，採用全身取景；對話框置於中下方，以半透明底色覆蓋部分身體。文字、輸入及操作按鈕保持可讀，長回覆在框內捲動。
- 橫向小裝置及矮身LED，使用緊湊左右布局，避免對話完全蓋住人物。
- 細屏與直向居民頁的導覽收到頂部把手。滑鼠移到上沿、點把手、從把手向下掃或按鍵盤均可打開。返回對話或按Escape收起；導覽展開不擠壓人物畫布。

Live2D按可見模型範圍取景；VRM只臨時調整可還原的顯示投影，不縮放模型或干擾頭髮物理。離開自動取景範圍會還原原有設定；AIRI管理預覽及已保存的角色、相機和動作參數不改。

畫面移除居民元件的固定最低闊度和人物最低高度。手機鍵盤令可視高度變小時，居民容器跟隨瀏覽器可視範圍；不關閉縮放或改瀏覽器權限。桌面瀏覽器的外框最小尺寸由瀏覽器及作業系統決定，網頁不能移除；測試256×768等尺寸可用Chrome DevTools的Responsive裝置模式直接輸入尺寸，真實LED則以其可用畫面自動判斷。這是CSS像素，不是假稱讀取螢幕硬件型號。

僅涉及居民顯示與導覽，保留Gemma、Microsoft語音、全部原資料、用量及控制、模型圖庫與選角、90日備份規則。沒有新增付費、供應商請求或機械人操作。瀏覽器與模型渲染模擬不能代替實際LED亮度、縮放、觸控及閱讀距離驗收。

參考：[Chrome官方Device Mode說明](https://developer.chrome.com/docs/devtools/device-mode)。
