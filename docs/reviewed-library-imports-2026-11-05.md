# 已審核模型來源的按需匯入

本批候選新增四個不同原檔摘要，來自三個已核對的 runtime 來源；不是二十個完整圖庫接入。原有 227 款不變，研究來源清單增加 AITuber OnAir 後為 21 項。只有可用清單內四款可一鍵預覽，其他研究來源沒有因此取得自動匯入資格。各來源的整站新增模型仍須個別核對，不能將作者、鏡像或改名檔案當作另一個平台。

鄰伴的主要用途是居民服務，圖庫只是管理員選擇該平台數字人的設定工具。本批不提供通用模型匯出或素材轉售。管理員須先勾選原作者條款及只在鄰伴作數字人使用的確認。發佈後，居民畫面「資料與私隱」保留作者、具體限制及原條款連結；獨立居民視窗亦有相同後備顯示。

Tsukuyomi 官方 ZIP 為 176,073,879 bytes。後端只接受程式內固定 URL、整包 SHA-256、唯一指定 member、單模型大小及 SHA-256；每次只容許一個下載，封鎖轉址，不帶居民資料、Cookie、OAuth 或 API key。原包串流到會自動清除的暫存檔，沒有把整包放進 RAM，也不會 extractall 或執行內容。上游檔案改變、限流或不可用即停，保留原角色，沒有自動重送。

開啟模型選單只讀本機 manifest，不會批量下載。若同一 SHA 已存在於裝置或平台共享清單，優先重用，避免再次下載大包。預覽只回傳經核對的原 VRM，尚未寫入資料庫或切換全平台；原有「儲存至平台」才發佈。單模型 32 MiB、共享模型總量 64 MiB 的限制不變，不會自動儲存四款或擴大上限。

隔離證據在 `.runtime/free-paths-20261105/library/`：四款結構驗證、與原有 227 款按 SHA 去重、真正 AIRI frontend88 預覽及截圖均完成。已直接檢查實際 mesh、貼圖、眨眼及 aa 嘴形權重變化；不是只等待空場景 mounted。176 MB 原包經實際新 importer 的本機分段重播及指定檔案抽取驗證，原 bytes 全同；該單程序 peak working set 為 83,783,680 bytes，不當作 Render 負載或雲端下載延遲。
