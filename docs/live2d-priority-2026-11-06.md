# Live2D 推薦與原創圖庫更新

用戶確認「80%」指預設推薦清單，以 Live2D 為主；全部原有 VRM 保留，不刪模型或用重複檔案湊比例。

「選擇模型」預設顯示 Live2D，可切換「VRM · 3D」、「所有格式」及免費骨架。搜尋新候選亦預設 Live2D。所有格式仍按首次加入／上載／匯入時間由新至舊排列，重複預覽不改時間；原有選用角色不變。

模型下載會顯示實際收到的百分比，完成後再核對完整檔案。大型模型按已核對大小給予較長、最多五分鐘的有限下載時間；網絡中斷或暫時逾時不會把有效模型誤當壞檔永久隱藏，大小／雜湊等真正完整性錯誤則繼續阻止使用，原角色保留。

本批加入原創系列另外十一款：Gothic Angel、Gothic Aristocrat、Gothic Kawaii、Gothic Lolita、Pink Aristocrat、Pink Kawaii、Pink Pastel、Snow Angel、Snow Aristocrat、Snow Dancer、Snow Pastel。逐款固定作者原檔及 SHA，經真正 AIRI／Cubism 渲染、嘴形及眨眼檢查，保留模型、貼圖、動作及 CC BY-NC 4.0 署名條款。它們是同一維護者的不同款式，不另計十一個獨立來源。

目前不同模型檔案共 264 款，Live2D 49 款、VRM 215 款；預設推薦是 Live2D 專區，並非聲稱整個庫的 Live2D 已佔 80%。真正合資格獨立原創來源仍為十八個，二十來源目標尚差兩個。

## 自動更新

已有 Live2D 官方、VTuber Nook、Aplaybox、BOOTH、itch.io 公開目錄檢查，另有已接入的 VRoid Hub。本批再加入 [Desktop Companion 作者](https://github.com/xShiroeNguyenx/desktop-companion) 的公開版本清單檢查。

每次職員進入後台會在背景檢查已接通來源，六十秒內多次進入合併一次；正常輪詢沿用快取，不阻住居民對話。原創來源先核對 [素材授權](https://github.com/xShiroeNguyenx/desktop-companion/blob/4a9170a13c4fb702e35c68a2311d5fa27088b6d5/ASSETS-LICENSE.md) 的已核指紋，再讀取固定原站的模型清單，不消耗 Tavily 搜尋額度。十八款已驗原檔不會重複當新款；真正新版本會留作待核候選。

授權變更、原站限流或格式錯誤時保留上次成功清單，不繞過登入／驗證、不下載未知檔案、不自動發佈或換角色。網上搜尋與候選數量不等於可用模型數；新款仍須授權、檔案及渲染檢查，才列入一鍵選擇。

## 免費及資料保留

新增 ZIP 按選擇時才下載，沒有啟動時下載全部模型。程式資產仍限制 256 MiB；獨立已核對圖庫的內部封裝上限由 96 MiB 調為 128 MiB，實際執行 ZIP 約 116.4 MiB。這是本系統的有限檔案檢查上限，不是增加官方額度、變更 Render 方案或開通付費；居民上載模型的原有 64 MiB 上限不變。

不清資料、不重置 quota、不改 API key、正式選用模型或服務供應商。保留 Gemma、Microsoft 語音 F0、Whisper／Tavily、MB842、原有簽名帳本與九十日備份規則；不連線、初始化、拍攝或移動機械人，不開真人鏡頭、咪高峰或播放。

## 來源研究的限制

本輪另外檢查免費模型目錄、BOOTH、itch.io、GitHub 原創庫及 CHARAT 等。部分模型只准個人／直播使用，部分只有 PSD／編輯工程，不能當成已可在 AIRI 播放。Generi-chan 作者原站本次回應 429，未重試繞過；kiriyuki 公開頁的執行程式限授權域名，未解混淆、移植或建立鏡像。學習用途不會自動取代作者條款。沒有因數量目標加入未獲准的遊戲拆包、鏡像或付費內容。
