## 現場及街外機械人控制

`edge_hub.hardware_agent` 只在 `127.0.0.1:8000` 提供原有 EP 控制台及 API，不啟動舊居民資料庫、個案、記憶或用量寫入者，也不移除 cloud-primary 防重複保護。啟動時只讀已保存機體清單，不啟動 SDK、搜尋、連線或鏡頭。原控制權、按住／放開停止、故障記錄、畫面過期及失聯停止保護保留，由職員明確操作。

- `START-ROBOT-CONSOLE.cmd`：現場控制程式；電腦必須與 EP 在同一網絡。
- `START-ROBOT-REMOTE.cmd`：沿用已批准的 Microsoft Store ngrok 免費安裝與既有帳戶，僅代理機械人路由，Google OAuth 加指定帳戶保護；不開放 EP 的 UDP／內網端口。
- 管理工作台新增「機械人控制」分頁，提供現場與街外入口。遠端網址只在職員設定 API 提供，不放進公開居民設定。

居民對話及管理資料可獨立於 Notebook 運行；EP 遙控需要現場電腦和現場網絡仍在運作。自動巡查辨識及新相片回報尚未從此硬件程式接通雲端，控制台會明示停用；舊雲端巡查資料仍保留，不能以重新啟動舊 native app 的方式補回。
