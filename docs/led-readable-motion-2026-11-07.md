# LED 大字與自然互動動作

極窄直向居民畫面會統一放大對話、輸入、按鈕與提示文字，全部不小於同畫面的「你好，慢慢傾」。256×768 約為18px；同樣比例的較大CSS尺寸會同比例放大。128px等極小畫面最低16px，對話區會往上擴展。長內容在對話區內捲動，保留輸入與主要按鈕；管理面板及一般手機、電腦版不受此大字規則影響。

修正上一版雙手長期抬到頭頂兩側的姿勢。VRM會輪流以單手在臉旁招呼，另一手自然放低，交接時短暫重疊；手腕持續輕擺，同時保留點頭、側頭聆聽、輕微轉身與環顧。鏡頭視線優先，關懷語境動作較柔和。隱藏頁面或減少動態設定會還原原有姿勢。

Live2D不同作者的參數範圍並不相同，現在只在原作已有參數上作小幅、平滑的動作，不再突然推到大幅度抬手的位置。沒有手臂參數的模型不會被強行生成手臂動作，仍可使用原有動作、點頭及身體互動。嘴形、眨眼、原模型、保存偏好與頭髮物理保留。

所有動作在裝置內運算，不新增AI、語音或搜尋請求。Gemma＋Microsoft語音及免費保護不變；不清資料、重設用量、改金鑰或操作EP／S1。實際LED亮度、觀看距離與角色觀感仍由現場驗收。
