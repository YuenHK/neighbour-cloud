# 細屏居民數字人上半身取景

直向手機、平板、智能電視、LED及緊湊細屏改為頭部和上半身取景。人物放大、頭頂靠近畫面上方，減少全身縮小造成的背景留白；下方半透明對話框及頂部抽屜導覽保留。普通橫向電腦布局、管理工作台及AIRI編輯預覽不改。

此項只改居民顯示層。Live2D按可見範圍集中取景；VRM只改可還原的相機投影，不縮放模型、不改動頭髮物理或已儲存的角色設定。改變視窗、方向或鍵盤高度不重開對話。寬袖、長髮及張開的手臂可能在近鏡時局部超出畫面，屬上半身構圖的裁切，不影響嘴形或動作。

Gemma、Microsoft語音、全部原有資料、用量、模型圖庫、90日備份及機械人狀態保持。實際LED亮度、縮放及觀看距離仍需在現場驗收。
