## 已核對甚麼？

820 項後端、112 項 Node、36 題離線對話題庫、網絡故障及 Chromium／WebKit 隔離測試通過；另有31項相關 Node 檢查。完整預覽測過七個管理分頁、原版 AIRI 設定存讀、模型選單、示範額度及虛擬機體介面。frontend96 的 lint、typecheck、build 全過，823個資產核對摘要；正式 HTTPS 的24項頁面及資產逐位元組核對。動畫錄影取樣曾有排程間隙，不作完整動畫效能認證。

原有個案、短編號、模型、設定、明確長期記憶、控制狀態、事件及刪除帳本核對保留；歷史用量沒有減少。沒有因介面更新而建立測試工單、改模型、開咪、播放音訊或操作機械人。

舊程序實際退出後，才建立新版本；再核對唯一新程序、等待至少90秒、比對原有資料並寫入獨立技術簽署。沒有更改金鑰、資料庫結構、供應商、免費方案或原有用量計數。

## 驗收與限制

用戶已確認廣東話對話、收音及朗讀、同一個案補充、查詢職員跟進、三分鐘交接，以及 Notebook 關機後手機使用。機械人與場地辨識效果、S1、定位及自主行車仍需按現場計劃驗收；手機工作提示實際送達仍待驗收。

完整技術證據在本機私有執行目錄，沒有上載居民資料或憑證。部署與復原仍須先確定唯一正式寫入者停止，不以滾動部署代替核實；開發者參閱 [雲端部署文件](../deploy/cloud/README.zh-Hant.md)。
