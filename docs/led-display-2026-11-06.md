# 直式 LED 小螢幕模式

居民服務台按瀏覽器實際可用畫面自動切換：闊度不超過256、高度不超過768 CSS像素即啟用。這不是螢幕硬件型號偵測。LED裝置建議以100%瀏覽器縮放、全螢幕使用；視窗尺寸改變會即時重新判斷，一般手機和桌面版保持原樣。

小螢幕模式把數字人和對話上下分配。Live2D按可見模型範圍臨時採用全身取景，VRM則臨時調整顯示投影，不縮放模型或干擾頭髮物理效果。兩者均不更改已儲存的模型、相機、角色、語音或平台設定；離開小螢幕模式會恢復原有取景。模型檔案、材質和授權標示不改。

對話區縮小字級和間距，保留文字輸入、語音及下一位等按鈕；長回覆在對話區內滾動，避免整頁被推長。更矮的小螢幕增加對話所佔比例，保留操作空間。

頂部品牌及導覽收進浮動抽屜，不佔用數字人畫面高度。滑鼠移到上沿會滑出，離開後收起；亦可點上沿把手或用鍵盤操作。進入服務畫面或按Escape收起，抽屜展開不會擠壓數字人。資料與私隱、作者署名及職員登入保留在抽屜，權限要求不變。
