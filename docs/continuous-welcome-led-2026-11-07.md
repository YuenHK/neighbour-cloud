# 持續揮手與窄LED近鏡

居民數字人顯示時使用獨立、持續的招手層，左右手輪流領先，手腕輕輕擺動。待機、聆聽、回答及關懷期間均可保留招手，原有點頭、情境動作及本機視線互動另外合成，不新增對話、聲音或AI請求。關懷語境的動作會較柔和。隱藏頁面或裝置要求減少動態時會暫停並還原。

VRM使用原有標準骨架，手臂採用靠近臉旁的招手姿勢，頭部及身體互動另外合成；不縮放模型，不改頭髮物理。Live2D只驅動模型實際存在的手臂／手腕參數；沒有手臂骨架的2D原作不能憑程式生出手臂，仍保留原有點頭和身體互動。管理模型預覽不會自動加上居民專用持續招手，已保存角色設定不改。

闊高比不大於2:5的極窄直向居民畫面，額外放大人物至上一版的兩倍，頭頂保持靠上，減少留白。256×768、512×1536等相同比例採用同樣規則，無需假稱讀到實體螢幕型號。半透明對話框向上擴展至畫面下方56%，不再受440px高度上限限制。長頭髮、手臂或下半身可在近鏡時局部裁切，普通手機、橫向電腦與管理面板保留原有布局。

原資料、Gemma＋Microsoft語音、所有免費額度與保護、316模型／20圖庫、90日備份及機械人狀態保持。本次不會開咪、播音、使用真人鏡頭，亦不連線或操作EP／S1。實際LED縮放、亮度與觀看距離仍需現場驗收。
