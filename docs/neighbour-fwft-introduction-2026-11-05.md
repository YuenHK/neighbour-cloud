# 鄰伴智慧社區平台：FWFT 團隊介紹稿

**「鄰伴智慧社區平台」是由 FWFT 團隊設計、具備情境理解與情感回應能力的統籌與主控 AI 平台。**我們希望透過數字人、巡查機械人及不同功能模組，照顧居民的身心靈需要，協助職員及早發現問題，並重新連結居民與社區的支援網絡。

我們把社區看成一個需要共同照顧的小生態圈。鄰伴聆聽居民，機械人提供現場線索，各子系統整理知識、關懷需要及環境問題，再由管理人員核實和跟進，讓支援更早到達。

平台參考《地平線》蓋亞的分工構思，以九個子功能規劃整體協作。這些名稱代表工作分工；部分功能已有實作，部分仍在測試或屬未來發展。

| 子功能 | 分工與功能 | 實作狀態 |
| --- | --- | --- |

我們希望鄰伴帶來的不只是更快的查詢或巡查，而是讓居民覺得有人聆聽、讓職員更容易接手，讓社區中的需要更早被看見。

## 展示及報告使用說明

「具備情境理解與情感回應能力」是團隊確認的介紹用語，不聲稱系統具有自我意識。九個子功能是協作架構及介紹方式，不表示目前已運行九個獨立大模型。現有 Gemma、Microsoft 語音服務及職員覆核流程保留，正式平台品牌維持「鄰伴智慧社區平台」。

平台載入時的燈號表示本次啟動檢查結果：綠色為就緒、藍色為處理中、紅色為異常；修復期間以柔和紅色流動線提示。尚未開發或仍待現場驗收的項目會另行標示，不以綠燈當作實機驗收結果，也不以燈號保證外部 API 一定可用。安全修復只採有界重試及重新連接，不會自行移動機械人、清除居民資料或恢復已用完的免費額度。

綠燈表示已收到本次程式或設定的就緒證據；藍燈表示正在處理；紅燈表示需要處理；柔和紅色流動線表示正進行有限次安全重連。未來發展及仍待現場驗收的功能保留灰色，動畫不會替它們改成綠色。入場動畫約2.52秒，只表達視覺展開，不是服務健康檢查的計時器。

畫面與真正載入同步進行，必要畫面準備好後可按「立即進入」跳過餘下展示；亦可由平台標題的「認識鄰伴」重播完整圓盤與清單介紹，選看各子功能及3D示意。裝置選擇減少動態時會直接顯示，離頁或關閉介紹後暫停動畫。這些展示不呼叫對話、朗讀或影像AI，不會使用額外免費AI額度。
