## 初音 Live2D 的核對結果

前次列出的初音款式不能全部直接加入公開共享庫：冷白茶 SD、Ruby「いますぐ輪廻」及 ElenaMumu Q版明確禁止未獲准的模型再傳播；Ink Miku 限個人用途；Alien Changeling Q版尚未見清楚的網站共享授權，原站本次回應 429，沒有重試繞過或建立鏡像。它們沒有被當成已匯入或已通過 AIRI 驗收。

另查到的 Steam「Miku Chibi Dayo」頁顯示項目被移除及不兼容；官方初音樣本涉及另行角色授權；沒有用遊戲拆包、他人轉載或單純 GitHub 程式碼 MIT 標籤代替模型授權。既有三款已核初音 VRM 保留可選。
